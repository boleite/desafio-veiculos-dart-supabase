# Desafio de Cadastro de Veículos

Aplicação de terminal em Dart para cadastrar, listar, atualizar e excluir veículos no Supabase.

## Requisitos

- Dart SDK 3.0 ou superior
- Projeto no Supabase
- Tabela `public.veiculos` criada e liberada para as operações exigidas pelo exercício

## 1. Criar a tabela no Supabase

No SQL Editor do Supabase, execute:

```sql
create table if not exists public.veiculos (
  id bigint generated by default as identity primary key,
  marca varchar(50) not null,
  modelo varchar(100) not null,
  ano integer not null,
  valor decimal(12,2) not null,
  quilometragem integer not null
);
```

Configure as permissões/RLS de acordo com o ambiente disponibilizado pelo professor. Não desative políticas de segurança em um projeto real apenas para fazer o exercício funcionar.

## 2. Configurar a conexão

1. Na raiz do projeto, copie `.env.example` e renomeie a cópia para `.env`.
2. No painel do Supabase, abra as configurações da API do projeto.
3. Preencha `SUPABASE_URL` com a URL do projeto.
4. Preencha `SUPABASE_PUBLISHABLE_KEY` com a chave publicável (publishable key) do projeto.
5. Não compartilhe nem envie o arquivo `.env` ao GitHub.

Exemplo de formato:

```env
SUPABASE_URL=https://SEU-PROJETO.supabase.co
SUPABASE_PUBLISHABLE_KEY=sua_chave_publica_aqui
```

## 3. Instalar dependências e executar

Na raiz do projeto, execute:

```bash
dart pub get
dart run bin/main.dart
```
